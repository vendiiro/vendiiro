# Hi, I'm Iiro

MSc student in Data-Centric Engineering. I build research and analysis tools for stock markets: data-driven, tested and open about their limits.

## Selected projects

- **[nordic-desk-public](https://github.com/vendiiro/nordic-desk-public)**: a personal long-term stock research desk in euros. A Python CLI builds static HTML pages (portfolio desk, risk what-ifs, rules-based stock analysis, forecasts checked against what happened afterwards). Every number is computed in Python and tested.
- **[market-leaderboard](https://github.com/vendiiro/market-leaderboard)**: ranks hand-picked watchlists like a leaderboard and shows how a mix of them spreads risk across sectors, countries and currencies. Python engine, schema-checked JSON, React front end.
- **[dip-dashboard](https://github.com/vendiiro/dip-dashboard)**: a nightly screen for sharp price drops in quality companies. It reports its own negative backtest result instead of hiding it.

## Tools

Python · SQL · TypeScript · React · pandas · Power BI

The tools here are for research and learning, not investment advice.
